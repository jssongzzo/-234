# 오답노트 (PWA)

수학 문제 사진에서 **빨간 채점 표시**와 **내가 쓴 풀이**를 지워 주는 웹앱입니다.
서버 없이 브라우저(기기) 안에서만 동작하며, GitHub Pages에 그대로 올려 배포할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. (예: `odap-note`)
2. 이 폴더의 **모든 파일**(`icons/` 폴더, `.nojekyll` 포함)을 저장소 최상위에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<내아이디>.github.io/<저장소이름>/` 로 접속됩니다.

> 모든 경로가 상대경로라서 저장소 이름이 달라도 그대로 동작합니다.

## 휴대폰에 앱처럼 설치

- Android(Chrome): 메뉴 → **앱 설치** (홈 화면의 "홈 화면에 앱 설치하기" 버튼도 가능)
- iPhone(Safari): 공유 버튼 → **홈 화면에 추가**

## 수정 후 다시 배포할 때

`sw.js` 맨 위의 `const CACHE = 'odap-v1'` 숫자를 올려 주세요(`v2`, `v3`…).
그래야 사용자 기기의 캐시가 새 버전으로 교체됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` / `style.css` | 화면 |
| `app.js` | 촬영·자르기·편집·저장 흐름 |
| `engine.js` | 이미지 처리(빨강 감지, 잉크 색 제거, 배경 복원) — 외부 라이브러리 없음 |
| `sw.js` / `manifest.webmanifest` | 오프라인 동작·설치(PWA) |
| `icons/` | 앱 아이콘 |

## 동작 원리와 한계

- **채점 표시**: 빨간색 계열 픽셀을 찾아 지우고, 주변 종이 색으로 자연스럽게 메웁니다. 문제 자체에 빨간 글씨/도형이 있으면 같이 지워질 수 있어 "빨간 채점 자동 지우기" 스위치와 민감도로 조절합니다.
- **펜 글씨(파랑·초록 등)**: "글씨 색" 도구로 글씨를 탭하면 같은 색이 모두 지워집니다.
- **연필·검정 풀이(손글씨 감지)**: "손글씨 감지" 도구를 처음 열면 자동으로 찾아서 지우고, 지운 곳을 노란 칸으로 보여 줍니다. 잘못 잡힌 칸은 탭해서 빼고, 놓친 곳은 브러시/영역으로 보충합니다.
  - 학습된 AI 모델이 아니라 **규칙 기반 분석**입니다. (1) 인쇄보다 옅은 회색이면 연필로 판단, (2) 한 줄로 묶었을 때 글자 높이·밑줄이 들쭉날쭉하면 손글씨로 판단합니다.
  - 합성 시험지 3장 기준 손글씨 재현율 약 88%, 인쇄 오탐 약 7%였습니다. 실제 사진에서는 달라질 수 있으니 반드시 노란 칸을 확인하세요.
  - 손글씨가 인쇄 글자에 붙어 있거나, 글씨가 인쇄처럼 반듯하면 틀릴 수 있습니다.
  - 나중에 학습 모델을 붙일 경우 `engine.js`의 `Engine.detectHandwriting` 한 곳만 교체하면 됩니다. (반환 형식: 성분 라벨 + 확인용 영역 목록)
